# Native Worker Delegation

Native delegation is the internal Implementation route. It uses a fresh,
narrow context and a compact return; it is not a manual EC, transport protocol,
dispatcher, or second design authority.

## Capability and value gate

Sol selects the least costly adequate capability: Luna for bounded discovery,
documentation, implementation, or deterministic verification; Terra for
stronger-judgment work and the normal independent review; and the separately
spawned `alp_escalation_reviewer` only as a read-only Sol review after explicit
user authorization. The root Sol orchestrator is distinct from that reviewer
and never performs repository work.

Delegate only for a concrete benefit: substantial cheaper work, root-context
protection, noisy-output compression, independent judgment, useful latency, or
separate external capacity. Skip when evidence is already in one or two small
named artifacts, material judgment is required in the root, briefing and
reconciliation cost more than the bounded work, or no suitable capability is
available. Record the decision briefly; do not delegate by habit.

## Fresh packet and closed boundary

Provide only a self-contained packet with:

- role or capability;
- bounded task and exact repository file boundary;
- relevant supplied evidence and paths;
- allowed permissions;
- stop conditions; and
- compact response requirements.

Include a working directory only when operationally needed. Do not copy a
transcript or broaden context. Workers may not recursively delegate, choose
material design, alter scope, authorize phases, redefine acceptance, or invent
compatibility behavior. One writer owns a shared checkout; parallel workers
need independent files and useful quota headroom.

## Return, failure, and timing

Every return states status/conclusion, concrete evidence, uncertainty or a
precise blocked reason, inspected scope, and uninspected scope. Implementation
and review returns also state changed files or reviewed diff, oracle results,
deviations, acceptance coverage, and residual risk. A conflict, missing
authority, failed approved oracle, unavailable capability, or material design
gap is a blocked result—not a reason to retry, use a fallback, or restore a
dispatcher. The root makes any new attempt a new decision.

Native spawning has no enforceable task timeout. A packet may include an
advisory time budget or checkpoint request when useful; it is advisory only and
does not promise interruption, cancellation, or worker termination.
