# Historical and External Source Handling

Status: Current non-governing process guidance.

Use this path rarely, for evidence that is useful to preserve but is not yet
current repository guidance. Every ingested source must record:

- original repository-relative provenance;
- status (for example historical, retired, or deferred research);
- portability (what was removed or generalized);
- disclosed sanitization or normalization; and
- reconciliation needed before any claim is promoted to current knowledge.

Preservation is not adoption. Reconcile claims against governing documents and
fresh repository evidence before linking them from current guidance. Keep
obsolete material out of current navigation while retaining durable historical
lessons when they have future value.
